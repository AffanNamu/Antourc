# AssistLink Mobile

Flutter Android client foundation. The current UI is a real application shell, not a simulated call. Calling, screen capture and remote interaction buttons remain disabled from a product-functionality perspective until their corresponding platform services are connected and verified.

## Setup
Run `flutter pub get`, `flutter analyze`, `flutter test`, then `flutter run` with Android SDK configured. See [root development guide](../../docs/DEVELOPMENT.md).

Package: `com.assistlink.app` · Minimum Android API: 26.
